# MANTIS V4 dependencies.

# installs. Every entry below is justified; nothing speculative is included.

# Supported production runtime: Python 3.11+ (64-bit recommended on Windows).

                       # missing while still printing "ET" (audit G-6). V4
                       # refuses to start instead, so this is not optional.

                       # (section 26D) and distribution/statistical tests

                       # calibration, reliability curves (sections 6 and 21)
